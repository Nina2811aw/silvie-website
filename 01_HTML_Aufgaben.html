HTML — das Skelett deiner Website

In diesen Aufgaben baust du das Grundgerüst für dein magisches Haustier. Es wird noch nicht hübsch aussehen — aber es wird alle Zutaten haben, die wir später brauchen!

⏱️ Geschätzte Zeit: 2–3 Stunden  ·  12 Aufgaben  ·  Tippe alles in den HTML-Bereich von liveweave.com

🌱 Erinnere dich

HTML ist wie das Skelett eines Körpers — es bestimmt, was auf der Seite ist, aber noch nicht, wie es aussieht. Jedes Element hat einen öffnenden Tag wie <p> und einen schließenden Tag wie </p>. Dazwischen kommt der Inhalt.

Eine id ist wie ein Namensschild — jedes Element kann nur eine bestimmte ID haben, und JavaScript wird sie später benutzen, um Elemente zu finden!

Aufgabe 1

🏠Das Grundgerüst

Liveweave hat das Grundgerüst meistens schon vorgegeben. Falls nicht, oder falls du es nochmal selbst tippen möchtest, sieht es so aus:

Beispiel 
<!DOCTYPE html>
<html lang="de">
<head>
  <meta charset="UTF-8">
  <title>Mein magisches Haustier</title>
</head>
<body>
  <!-- Hier kommt alles rein, was man sehen soll -->
</body>
</html>
Deine Aufgabe

Schreibe alles weitere in liveweave innerhalb von <body>...</body>.

Ich habe das Grundgerüst und weiß, wo der Inhalt hinkommt.
Aufgabe 2

📛Eine große Überschrift

Jede Website braucht einen Titel. Bei uns wird das der Name deines Haustiers sein.

Beispiel 
<h1>Sternchen</h1>
Deine Aufgabe
  • Schreibe ein <h1>-Element ins <body> mit dem Namen deines Haustiers (du erfindest ihn).
  • Darunter ein <p> mit einem Untertitel, z.B. "Mein magisches Haustier".
💡 Tipp

Es gibt <h1> bis <h6> für unterschiedlich große Überschriften. <h1> ist die größte!

Aufgabe 3

🦄Der Pet-Bereich

Jetzt brauchen wir einen Bereich, in dem dein Haustier "wohnt". Dafür benutzen wir <div> — das ist ein Container, eine unsichtbare Box, in die andere Sachen reinkommen.

Beispiel 
<div id="pet-bereich">
  <p id="pet">🦄</p>
  <p id="pet-stimmung">fühlt sich wohl</p>
</div>
Deine Aufgabe
  • Erstelle ein <div> mit der id pet-bereich.
  • Im <div>: ein Emoji für dein Haustier (🦄, 🐱, 🐉, 🐰, ...) — was du magst!
  • Darunter ein <p> mit der id pet-stimmung und Text wie "fühlt sich wohl".
💡 Tipp

IDs müssen einzigartig sein — also keine ID zweimal verwenden. JavaScript wird die IDs später benutzen, um Sachen zu verändern!

Aufgabe 4

📊Die Status-Anzeigen

Dein Haustier hat drei Zustände: Hunger, Glück und Energie. Jeder zeigt einen Wert von 0 bis 100. Wir brauchen für jeden Wert ein eigenes Element mit einer ID.

Beispiel 
<div id="status">
  <p>🍓 Hunger: <span id="hunger">80</span></p>
  <!-- Glück und Energie genauso -->
</div>
Deine Aufgabe
  • Mach ein <div> mit der id status.
  • Mach drei <p>-Elemente — eins für Hunger, eins für Glück (id glueck), eins für Energie (id energie).
  • Setze den Anfangswert in jedem auf 80.
💡 Was ist <span>?

Wie <div>, aber für kleinere Sachen innerhalb einer Zeile. Perfekt um nur die Zahl zu markieren, nicht den ganzen Text.

Aufgabe 5

🔘Die Aktions-Buttons

Drei Buttons, mit denen man dein Haustier füttern, mit ihm spielen oder es schlafen legen kann.

Beispiel 
<div id="buttons">
  <button id="btn-fuettern">🍎 Füttern</button>
  <!-- weitere Buttons hier -->
</div>
Deine Aufgabe
  • Container <div> mit der id buttons.
  • Drei <button>-Elemente mit den IDs btn-fuettern, btn-spielen, btn-schlafen.
  • Schreibe schöne Beschriftungen mit Emojis ins Innere der Buttons.
💡 Tipp

Wenn du jetzt auf die Buttons klickst, passiert noch nichts. Das ist normal! Die Logik kommt mit JavaScript in Woche 3.

Aufgabe 6

🍓Das Futter-Inventar (eine Liste)

Welche Snacks hat dein Haustier zur Auswahl? Listen mit Aufzählungspunkten macht man mit <ul> (unsortierte Liste) und <li> (Listenpunkt).

Beispiel 
<h2>Mein Futter</h2>
<ul id="inventar">
  <li>🍎 Apfel</li>
  <li>🍰 Kuchen</li>
</ul>
Deine Aufgabe
  • Eine <h2>-Überschrift mit "Mein Futter" oder "Snackvorrat" oder was du willst.
  • Eine <ul> mit der id inventar.
  • Mindestens 5 verschiedene Futter-<li>'s mit Emojis. Wähle, was zu deinem Haustier passt!
💡 Mehr Listen?

Es gibt auch <ol> (ordered list) — da werden die Punkte mit 1, 2, 3 nummeriert.

Aufgabe 7

✏️Pet umbenennen — ein Eingabefeld

Was, wenn man dem Haustier einen anderen Namen geben möchte? Dafür brauchen wir ein <input> — ein Textfeld zum Eintippen.

Beispiel 
<div id="umbenennen">
  <label for="name-input">Neuer Name:</label>
  <input type="text" id="name-input" placeholder="z.B. Sternchen">
  <button id="btn-umbenennen">Umbenennen</button>
</div>
Deine Aufgabe
  • Erstelle einen Bereich zum Umbenennen (siehe Beispiel).
  • Wichtig: Das <input> braucht die id name-input.
  • Der Button braucht die id btn-umbenennen.
💡 Was ist placeholder?

placeholder ist der graue Text, der im Feld steht, bevor man etwas tippt — wie ein Hinweis.

Aufgabe 8

🌙Tag/Nacht-Schalter

Schlafenszeit! Mit einem Knopf können wir später zwischen Tag- und Nachtmodus umschalten.

Deine Aufgabe
  • Mache einen <button> mit der id btn-tagnacht.
  • Beschriftung: "🌙 Nacht / ☀️ Tag" oder ähnlich.
💡 Wozu?

Mit JavaScript werden wir später den Hintergrund dunkel machen, wenn man auf diesen Knopf drückt — dein Haustier schläft dann!

Aufgabe 9

📔Das Tagebuch

Hier soll später erscheinen, was passiert ist — z.B. "Du hast Sternchen gefüttert!". Das ist nur ein leerer Bereich, in den JavaScript Texte einfügen wird.

Beispiel 
<h2>Tagebuch</h2>
<ul id="tagebuch">
  <li>Sternchen ist erwacht...</li>
</ul>
Deine Aufgabe
  • Eine <h2>-Überschrift "Tagebuch".
  • Eine <ul> mit der id tagebuch.
  • Ein erster <li>-Eintrag — z.B. "[Pet-Name] ist erwacht...".
Aufgabe 10

🦶Footer — der Fuß der Seite

Ganz unten kommt ein <footer> — das ist ein semantisches Element, das HTML mitteilt: "Hier ist der Schluss".

Beispiel 
<footer>
  <p>Mit Liebe gemacht von [Dein Name] 💖</p>
</footer>
Deine Aufgabe
  • Mach einen <footer> ganz am Ende des <body>.
  • Schreib deinen Namen rein (oder einen kreativen Künstlernamen 😉).
  • Optional: Das aktuelle Jahr.
Aufgabe 11

📦Alles in Sektionen ordnen

Stell dir vor, deine Seite ist ein Buch — jeder Abschnitt sollte logisch zusammengehören. Dafür gibt es <section>. Es ist wie ein <div>, aber mit Bedeutung.

Deine Aufgabe
  • Wickle die Aktions-Buttons (Aufgabe 5) zusätzlich in eine <section> mit der class aktionen.
  • Wickle das Inventar in eine <section> mit der class inventar-bereich.
  • Wickle das Tagebuch in eine <section> mit der class tagebuch-bereich.
💡 id vs. class

id = einmalig, jedes Element hat seine eigene. class = wiederverwendbar, mehrere Elemente können dieselbe Klasse haben. CSS und JS können beides nutzen.

Aufgabe 12 ✨

🎨Bonus: Mach es zu deinem!

Du hast jetzt alle "Pflicht"-Elemente. Jetzt kommt die Kür: Was würde deine Seite noch perfekter machen?

Ideen — wähl 1-2 aus
  • Eine zweite Liste mit "Lieblingssachen" deines Haustiers (Farbe, Spielzeug, Lieblingstanz...).
  • Ein Bereich "Tagesstatistik" mit drei <span>'s wie fuetterungen-heute, spiele-heute.
  • Ein <img>-Element mit einem Bild deines Haustiers (z.B. von flaticon.com oder einem Screenshot).
  • Ein "Über mich"-Bereich, in dem das Haustier sich selbst vorstellt.
  • Mehrere "Stimmungen" als versteckte Texte (id-Beispiele: stimmung-glücklich, stimmung-müde).
💡 Wenn du ein Bild einfügen willst 
<img src="https://link-zum-bild.png" alt="Mein Haustier">

Achtung: Ein Link muss direkt auf eine Bilddatei zeigen, nicht auf eine Webseite mit Bildern.
